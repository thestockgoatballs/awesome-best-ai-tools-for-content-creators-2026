# Contributing

Thanks for contributing to `awesome-best-ai-tools-for-content-creators-2026`.

## Submission Requirements

- Every tool must have a public `github.com` repository URL.
- No proprietary SaaS products or cloud-only tools without source code.
- No product homepages, waitlists, or docs-only links unless they point to the actual GitHub repository.
- Prefer projects that are clearly useful to content creators for writing, research, image generation, editing, audio, subtitles, voice, or video.
- If a category is weak, say so honestly instead of padding with unrelated repos.

## What To Include

For each submission, include:

- Repository name
- GitHub URL
- Short description based on the project README
- Primary use case for content creators
- License, language, stars, and recent activity if available

## Quality Bar

- Verify the repo exists and is public.
- Avoid duplicates and near-duplicates.
- Prefer actively maintained repositories over stale experiments.
- If the repo is archived, experimental, or research-heavy, mention that clearly.
- Do not submit closed wrappers around paid APIs unless the repository itself provides meaningful open source functionality.

## Pull Request Checklist

- The tool has a `github.com` URL
- The tool is relevant to content creators
- The description is factual
- The formatting matches the README structure
- The repo is not proprietary SaaS

## Reporting Issues

Open an issue if:

- A repository was removed or made private
- Licensing changed
- A better GitHub source exists
- Metadata in the README is outdated

## Style Notes

- Keep entries concise and specific.
- Use Markdown only.
- Preserve category ordering unless there is a strong reason to change it.
